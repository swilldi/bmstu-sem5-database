# ЛР5 — задания

База — из ЛР1. JSON-столбцы — `car.specs` и `race_entry.pit_stops` (структура в [json-columns.md](json-columns.md), данные в `data/car_specs.json` и `data/pit_stops.json`).
Справка по командам — [commands.md](commands.md). Сдавать одним `lab05.sql`, разделённым по пунктам.

19 заданий: каждое закрывает пункт методички и отрабатывает несколько команд (они указаны в конце задания).
Изменяющие запросы (задания 15–16) выполняйте внутри `BEGIN; ... ROLLBACK;`, чтобы не портить данные.

## Пункт 1. Выгрузка в JSON

**1. Строка таблицы → JSON.**
- Выведите трассы объектами двумя способами и объясните, почему порядок ключей разный.
- Выведите пилотов объектами со своими ключами: `id`, `name`, `born`, `country`.
- Выведите трассы массивами-кортежами: `["Monza", "Italy", 5.79]`.

*Команды:* `to_jsonb`, `row_to_json`, `jsonb_build_object`, `jsonb_build_array`

**2. Таблица → один документ.**
- Выведите всю таблицу `team` одним массивом, отсортированным по `team_id`, с отступами.
- Соберите словарь «страна → число трасс»: `{"Italy": 12, ...}`.

*Команды:* `jsonb_agg ... ORDER BY`, `jsonb_pretty`, `jsonb_object_agg`

**3. Вложенный документ — протокол гонки.** Для одной гонки (трасса + дата):
```jsonc
{
  "track": { "name": "...", "country": "..." },
  "date": "1950-05-13",
  "results": [ { "position": 1, "driver": "...", "status": "finished", "best_lap_s": 111.792 } ]
}
```
`best_lap_s` — число секунд. Результаты по `finish_position`, сошедшие в конце, у сошедших нет ключей со значением `null`.

*Команды:* `jsonb_build_object`, `jsonb_agg`, `extract(epoch ...)`, `jsonb_strip_nulls`

**4. Вся БД в JSON.** Напишите функцию `db_to_jsonb(p_exclude text[])`, которая берёт таблицы из каталога и собирает документ `{таблица: [строки]}`, пропуская таблицы из `p_exclude` (например, `json_import`). Сохраните результат в `db.json` одной командой из терминала, не заходя в `psql`.

*Команды:* `information_schema.tables`, `EXECUTE format('%I')`, `psql -At -c ... -o`

## Пункт 2. Загрузка из файла

**5. Полный цикл «таблица → файл → таблица».**
1. Сохраните результат задания 2 (массив `team`) в `team.json`.
2. Загрузите файл в таблицу-журнал `json_import` одним документом.
3. Создайте `team_copy` той же структуры и заполните из журнала.
4. Докажите совпадение: `EXCEPT` в обе стороны — 0 строк; столбцы, типы и `NOT NULL` совпадают.
5. Добавьте то, что `LIKE` не скопировал: внешний ключ `team_parent_id` → `team_copy`.
6. Посмотрите значение по умолчанию у `team_copy.team_id`: какую последовательность оно использует? Сделайте копии свою и выставьте на `max(team_id)`.

*Команды:* `\t on`, `\a`, `\o`, `pg_read_file` или ``\set content `cat ...` ``, `CREATE TABLE ... LIKE ... INCLUDING ALL`, `jsonb_populate_recordset`, `EXCEPT`, `setval`

**6. Ошибка загрузки.** Испортите `team.json`: поставьте одной команде `"founded_year": 1800`. Повторите загрузку и объясните, какое ограничение сработало и откуда оно взялось в копии.

*Команды:* `CHECK`, `LIKE ... INCLUDING ALL`

## Пункт 3. Столбец JSON

**7. `json` и `jsonb`.** Приведите литерал `'{"b": 1,   "a": 2, "b": 3}'` к обоим типам и объясните разницу: дубли ключей, пробелы, порядок.

*Команды:* `::json`, `::jsonb`

**8. `car.specs`.**
- Добавьте столбец и ограничение «всегда объект».
- Заполните из `data/car_specs.json` одним `UPDATE ... FROM`. Проверьте, что не осталось машин без `specs`.
- Добавьте одну машину через `INSERT` с литералом: турбо-гибрид V6 с `ers_kw`, `aero` с `drs`, двумя спонсорами.

*Команды:* `ALTER TABLE ... ADD COLUMN`, `CHECK (jsonb_typeof(...))`, `UPDATE ... FROM jsonb_to_recordset(...)`, `INSERT ... ::jsonb`

**9. `race_entry.pit_stops`.**
- Добавьте столбец и ограничение «всегда массив», заполните из `data/pit_stops.json` (связь по `driver_id` + `race_date`).
- Проверьте правдоподобность: нет пит-стопов на круге больше `laps_completed` и нет стопов у заездов `dns`.

*Команды:* то же, что в 8, плюс `jsonb_array_elements` для проверки

*Команды:* `->>` в `GROUP BY` / `ORDER BY`, `jsonb_array_length`

## Пункт 4.3. Проверка существования

**13. Ключи.**
- Разделите машины на три группы и посчитайте каждую: «нет `aero`», «`aero` есть, но нет `drs`», «`drs` есть».
- Машины, у которых есть хотя бы один из ключей `aero` / `sponsors`; и у которых есть оба.
- Вставьте машину со `"aero": null` и сравните `specs ? 'aero'`, `specs -> 'aero' IS NULL`, `specs ->> 'aero' IS NULL`. Объясните разницу.

*Команды:* `?`, `?|`, `?&`, `-> IS NULL`

**14. Значения и условия.**
- Машины с турбированным V6; машины со спонсором `Pirelli`.
- Машины с гибридом — оператором и функцией.
- Машины быстрее 300 км/ч — условием JSONPath; машины со спонсором на букву «P».
- Машины с `aero.drs` — стандартной функцией.

*Команды:* `@>`, `@?`, `jsonb_path_exists`, `@@`, `like_regex`, `JSON_EXISTS`

## Пункт 4.4. Изменение документа

**15. Добавление и замена.**
- Увеличьте `top_speed_kmh` на 5 у омологированных машин сезонов от 2020 (новое значение считается из старого).
- Выставьте `aero.drs = true` турбированным машинам, у которых есть `aero`.
- Добавьте спонсора в конец массива `sponsors` одной машины, другому — в начало.
- Добавьте всем машинам ключ `"checked": true`.

*Команды:* `jsonb_set`, `to_jsonb`, `jsonb_insert`, `||`

**16. Удаление.**
- Удалите `engine.hybrid` у машин до 2014 года; у одного заезда — первый пит-стоп.
- Переименуйте ключ `top_speed_kmh` → `vmax_kmh` у всех машин.
- Выполните `jsonb_set(specs, '{aero}', NULL)` — что получилось и почему? Сделайте правильно через `jsonb_set_lax`.

*Команды:* `#-`, `- n`, `- 'key'`, `jsonb_set_lax`
